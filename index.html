Section 01

Staff conduct

Every staff member represents EVILSMP in-game and on Discord. These expectations apply to everyone, at all times.

Section 02

Ranks & chain of command

Escalate only when needed, and always to the lowest appropriate rank first. Select a rank to see its role.

🛠️ Developers are not part of the moderation chain. They report to the Owner and should only be contacted for bugs, machine errors and plugin issues. Always include a recording and steps to reproduce.
Section 03

Staff commands

Each rank includes everything from the ranks below it. Click a command to copy it. Using /punish <player> is required for all punishments; this is only an overview of permissions.

Section 04

Punishments

Each offense escalates step by step with every repeat. Use judgement: context, intent and history can raise or lower a punishment.

Take a screenshot of the punishment first. Mute / ban evasion, IP bans and IP mutes are handled by Admin+.

📝 Required log format

Log every in-game punishment in #staff-reports. Missing logs can lead to a warning or a strike.

Username: <user>
Reason: <detailed explanation>
Duration: <time>
Proof: <screenshots / video / logs>

💬 Discord punishments

  1. Copy the user ID (right-click → Copy User ID, Developer Mode must be on).
  2. Check history with ?modlogs <ID> before deciding.
  3. Apply it with ?mute <ID> <duration> <reason>.
  4. Log it with ID, reason, duration, proof and context.
  5. Escalate severe or repeat cases to Admin+, following the hierarchy.

Ticket panels

Who can access which panel.

PanelAccess

Staff Team = Helper to Sr. Mod. Staff Management = Sr. Admin, Admin with permissions and Manager+.

Appeals

  1. Player opens an appeal with their username and the punishment reason.
  2. Review the evidence: logs, screenshots and the original staff member's notes. Never review your own punishments.
  3. Discuss if unsure. Ask another staff member or an Admin before reducing or removing a long ban.
  4. Reply clearly: accepted, reduced or denied, always with a short, polite reason.
